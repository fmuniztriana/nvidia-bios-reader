# NVIDIA BIOS Reader v0.4.0-beta.1

This is a public research **pre-release**. Keep v0.3.0 for the most conservative
stable experience. The beta remains read-only and never modifies a ROM.

## Highlights

- inspect every byte of each complete timing record, not only CONFIG0..CONFIG5;
- compare two Memory Support entries with `--compare-profiles A B`;
- compare entries directly in the native Windows GUI;
- inspect RAMCFG translation bytes, targets, aliases, and undeclared codes in
  both GUI and CLI;
- identify equal decoded timings whose complete records still differ;
- group byte-identical records using CRC32 fingerprints;
- inspect raw and resolved pointers for memory, training, TMRS, clock, and
  tweak structures;
- view complete records in the Windows GUI and exported reports;
- build the portable CLI on Linux using the new step-by-step guide.

## Why this beta exists

A controlled GA104 comparison showed that Samsung 8 Gbit and 16 Gbit profiles
can expose identical decoded low-range timings while still differing later in
their 76-byte records. The same physical-strap experiment changed requested
geometry, MRS values, electrical parameters, and training behavior. This beta
makes those previously hidden differences reproducible without assigning
unsupported names to unknown fields.

Read the complete
[GA104 case study](../research/ga104-8gbit-vs-16gbit.md).

## Example

```text
nvidia-bios-reader-cli card.rom --compare-profiles 1 7
```

The report distinguishes:

```text
Decoded CONFIG0..CONFIG5: IDENTICAL
Complete raw record: DIFFERENT

+0x2C: 0A -> 4A
+0x2D: 04 -> 03
+0x2E: 00 -> 90
+0x33: A2 -> A3
```

## Known limitations

- bytes after record offset `+0x17` are preserved but not semantically named;
- pointer resolution is validated on the current corpus but unusual PCI-image
  layouts remain experimental;
- `FULL` means complete timing-map coverage, not verified hardware support;
- timing ranges are selector intervals and are not direct P-state names;
- no VBIOS editing or flashing functionality is provided.

## Testing requested

Developers and hardware researchers are especially invited to test:

- Turing, Ampere, and Ada ROMs with timing-record strides other than 76 bytes;
- 8/16 Gbit pairs from the same vendor;
- GDDR6X and clamshell-capable profiles;
- ROMs containing multiple PCI images or unusual pointer layouts;
- comparisons against physically verified production memory part numbers.

Please follow the [validation workflow](../validation.md) and do not upload ROM
files without redistribution permission.

## Builds

The Windows release includes the native GUI and CLI. Linux provides the CLI.
See [Building NVIDIA BIOS Reader](../building.md) if a prebuilt Linux artifact
