# NVIDIA BIOS Reader v0.4.0-beta.2 — Experimental GDDR7 Support

**The main change is experimental GDDR7 memory-profile reading in both the Windows GUI and CLI.**
This is a research pre-release. The reader remains strictly read-only; it never edits or flashes a ROM.

## What is new

- Recognize GDDR7 descriptors in the observed memory-information layout.
- Inspect manufacturers, descriptors, offsets, declared RAMCFG translations and timing-reference coverage.
- Show inferred four-channel x32 and two-channel x16/clamshell device organization.
- Label density code 7 as **24 Gbit (inferred)**.
- Compare complete raw timing records without pretending their field meanings are already known.
- Flag records with a zero 24-byte prefix and nonzero data in the remaining bytes.
- Include reproducible research scripts and documentation covering consumer and professional Blackwell samples.
- Support Unicode ROM filenames, including Russian and Chinese, and display VBIOS versions in public builds.

## Important experimental limits

**GDDR7 clock units, P-state mapping and named timing decoding are not validated.**
The GUI therefore displays raw ranges and `Unvalidated (GDDR7)` instead of converted clocks.
CONFIG0–CONFIG5 decoding and decoded-field comparisons are disabled for GDDR7;
complete raw-record comparisons remain available.

Organization and 24 Gbit density are empirical interpretations, explicitly labelled as inferred.
Stored profiles and declared RAMCFG mappings do not identify the active physical configuration.
`FULL`, `PARTIAL` and `EMPTY` describe structural reference coverage only—not boot success,
training, stability, or suitability for a memory upgrade. Unknown GPU chip-name mappings may
still appear as `Unknown (BIOS code ...)`. This is not complete Blackwell support.

## Validation and research

- Report/comparison checks against 59 GDDR7 samples (58 distinct ROM hashes).
- Four legacy GDDR6/GDDR6X samples compared against the previous internal build,
  with unchanged decoded timing values, raw records and coverage.
- Unicode-path, truncated-input and unsupported descriptor-layout checks.
- Windows GUI/CLI and Linux CLI built by GitHub Actions.

## Downloads

- **Windows x64:** GUI and CLI; extract the ZIP before running.
- **Linux x64:** CLI; extract and run `chmod +x nvidia-bios-reader-cli` if needed.
- `SHA256SUMS.txt` lists SHA-256 checksums of both download archives.

No ROM files are distributed. Keep v0.3.0 for the most conservative stable experience.
