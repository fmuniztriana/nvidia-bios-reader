# NVIDIA BIOS Reader v0.2.0

Initial public research release by
[Felipe Muniz (`@fmuniztriana`)](https://github.com/fmuniztriana).

NVIDIA BIOS Reader began as an investigation into the low-P-state instability
seen on some graphics cards after double-density memory modifications. A GTX
1650 8 GB experiment showed that affected 16 Gbit profiles could contain
missing (`FF`) low-clock timing references while retaining populated high-clock
ranges. This release turns that observation into a reproducible, read-only
inspection tool.

## Highlights

- native standalone Windows graphical interface;
- portable command-line interface;
- GPU chip, PCI ID, and VBIOS version identification;
- GDDR memory vendor, density, organization, and physical strap mapping;
- `FULL`, `PARTIAL`, and `EMPTY (all FF)` timing-coverage classification;
- frequency-range, timing-ID, map-offset, and record-offset reporting;
- experimental CONFIG0 through CONFIG5 field decoding;
- detailed plain-text report export.

## Validation scope

The parser has been exercised against real TU106, TU116, and GA102 ROMs.
Related Turing, Ampere, and Ada layouts remain experimental until validated
against broader ROM sets and independent tools.

## Important limitations

This is a research tool, not a VBIOS editor or flasher. The source ROM is never
modified. Memory Support entries describe profiles available in the firmware;
they do not by themselves prove the memory physically installed on a board.
Several field names and the displayed-clock conversion are reverse-engineered
or inferred and are labeled accordingly.

See the README for the complete project history, interpretation rules, public
research references, and build instructions.
